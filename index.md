# 📊 clocwork - See Your Code History in One Dashboard

## 🚀 What Is clocwork?

clocwork is a free, easy-to-use tool that looks at your entire coding project's history and shows you important information in a simple, visual dashboard. Think of it like a fitness tracker for your code—except instead of counting steps, it counts lines of code, tracks AI-assisted work, and shows you how much time (or money) you've invested.

This tool is perfect for developers, project managers, and curious coders who want to understand their projects better without digging through complicated technical data.

## ⚡ Why Should You Use clocwork?

- **See Everything at a Glance**: clocwork puts all your project statistics into one clean, colorful dashboard. No more searching through multiple tools—everything is right there.
- **Track AI Collaboration**: If you use AI coding assistants like Claude, Codex, or Gemini, clocwork shows you exactly which parts of your code were co-authored with AI help.
- **Understand Your Investment**: clocwork calculates the token cost of your project. Tokens are how AI systems measure the work they do. Knowing this helps you budget and plan better.
- **Measure Your Project's Growth**: Watch lines of code grow over time, see which programming languages you use most, and spot trends in your development habits.
- **Works with Any Git Project**: If your code is stored in Git (the most popular version control system), clocwork can analyze it. It supports all major coding languages.

## 🎯 What Can You Do with clocwork?

Here's what you'll see in your clocwork dashboard:

### 📈 Lines of Code by Language
See a breakdown showing how many lines of code you've written in each programming language. Whether you're using Python, JavaScript, or something else, you'll know exactly what's in your project.

### 🧠 AI Co-Authored Commits
If you work with AI coding tools, clocwork highlights which changes were made with AI assistance. This helps you understand your own work patterns and shows the value AI tools bring to your projects.

### 💰 Token Cost Analysis
AI tools charge based on tokens (pieces of text they process). clocwork calculates the total token cost across your project's history. This is invaluable for budgeting and understanding the true cost of AI-assisted development.

### 🗓️ Historical Trends
Watch your project evolve over time. clocwork creates charts showing how your codebase changed day by day, week by week, or month by month.

### 🗂️ Supported Languages
clocwork works with virtually every programming language including Python, JavaScript, TypeScript, Java, C++, Go, Ruby, PHP, SQL, HTML, CSS, and many more.

## 🧰 Troubleshooting Tips

### Problem: clocwork won't start
- Make sure you've extracted all files from the ZIP archive
- Check that your Windows system meets the minimum requirements
- Try right-clicking the clocwork icon and selecting **"Run as Administrator"**

### Problem: Dashboard is empty
- Verify that your project folder is actually a Git repository (it should have a `.git` folder inside)
- Make sure you have the correct permissions to read the files in your project

### Problem: Analysis takes too long
- Close other programs to free up memory
- For very large projects, consider analyzing a subfolder instead of the entire project
